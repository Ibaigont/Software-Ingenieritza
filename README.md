## 📖 Deskribapena
[Idatzi hemen azalpen zehatzagoa. Zein arazo konpontzen du zure softwareak? Nortzuk dira erabiltzaile nagusiak?]

Adibidea: *Sistema honek erabiltzaileei beren hegaldi-erreserbak modu intuitiboan kudeatzeko aukera ematen die, administratzaileentzako funtzionalitateak barne hartuz, hala nola ibilbideak bertan behera uztea edo aldatzea.*

## ✨ Ezaugarri Nagusiak
* **Erabiltzaileen Kudeaketa:** Erregistroa, saio-hasiera eta rolak (Admin/Erabiltzailea).
* **Datu-basea:** Datuen persistentzia [MySQL / SQLite / ObjectDB] erabiliz.
* **Interfaze Grafikoa:** [Swing / JavaFX / Web] bidez garatutako interfazea.
* **Probak:** Unitate-probak [JUnit / Mockito] erabiliz.
